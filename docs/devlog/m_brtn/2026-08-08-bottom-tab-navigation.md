# Squinder: единый нижний tab-навбар и Phosphor Icons

**Автор:** m_brtn  
**Дата:** 2026-08-08, 23:03 EEST  
**Ветка:** `main`  
**Базовый коммит:** `d8b69f8` (`Update HomeScreen to format last ping time with detailed time components`)  
**Связанные задачи:** без трекера

## Контекст

Экран свайпов содержал локальную панель из пяти разделов, однако большая часть
пунктов не имела соответствующих экранов и была отключена. На Home и Appearance
нижней навигации не было, поэтому панель не являлась общей структурой приложения.

Для первого рабочего варианта решено использовать только три существующих
экрана: Home, Squinder и Appearance. После проверки визуального направления для
иконок выбран Phosphor: все пункты используют fill-вариант, а активный отличается
только цветом.

## Что сделано

### 1. Подключена tab-навигация

- Добавлен `@react-navigation/bottom-tabs`, совместимый с текущим React
  Navigation 7.
- Authenticated navigator переведён с native stack на типизированный bottom-tab
  navigator.
- Начальным экраном сохранён Home.
- Переходы с Home на Squinder и Appearance, а также переход из меню свайпера в
  Appearance продолжают работать через navigator.

### 2. Реализован общий нижний навбар

- Добавлен компонент `BottomNavBar` с пунктами Home, Squinder и Appearance.
- Каждый пункт показывает Phosphor-иконку и подпись.
- Все иконки используют вес `fill`; жирность подписи при переключении не
  меняется.
- Активная вкладка использует `text-primary`, остальные —
  `text-muted-foreground`.
- Панель использует semantic color tokens и нижний safe area устройства;
  верхний разделитель убран.
- Высота основной области начинается с 56 px, иконки имеют размер 26 px, а
  внутренние отступы и расстояние до подписи сделаны компактнее.
- Нижний safe area исключён из route-контейнеров, чтобы контент доходил до
  navbar; на свайпере сохранён визуальный отступ 16 px.
- Подсветка фона при тапе удалена; вместо неё вся tap-зона временно снижает
  opacity до `0.55`.
- Реализованы события `tabPress` и `tabLongPress`, accessibility role, label и
  selected state.

### 3. Адаптированы существующие экраны

- Из `SwiperScreen` удалена локальная пятиэлементная панель, чтобы не дублировать
  глобальную навигацию.
- Из Appearance убрана кнопка назад: экран теперь является корневой вкладкой, а
  не вложенным stack-route.
- Для вкладок выбраны `HouseIcon`, `SparkleIcon` и `GearIcon` из Phosphor.
- Верхние кнопки Undo и Menu на свайпере переведены на
  `ArrowCounterClockwiseIcon` и `ListIcon` с весом `bold`.
- Navbar рендерит Phosphor напрямую с размером 26 px и получает semantic colors
  через native-мост темы; для gluestack-кнопок в шапке добавлен отдельный
  адаптер цвета и размера.

### 4. Обновлена локализация

- Подписи трёх вкладок вынесены в ключи `navigation.*`.
- Удалены больше не используемые подписи старого navbar свайпера.
- Пользовательский текст не захардкожен в TSX.

## Архитектурные решения

- **Navbar принадлежит navigator, а не отдельному экрану.** Это гарантирует
  одинаковую навигацию и состояние выбранной вкладки на всех authenticated
  экранах.
- **Используется кастомный tab bar поверх React Navigation.** Навигационное
  состояние и события остаются стандартными, а визуальная часть использует
  локальные gluestack-компоненты и semantic tokens.
- **Начертание navbar-иконок остаётся постоянным.** Все вкладки используют
  `fill`, а выбранный раздел определяется только семантическим цветом.
- **В navbar включены только реализованные экраны.** Заглушки People, Liked You
  и Chats удалены до появления реальных продуктовых сценариев.
- **Safe area вычисляется динамически.** Inline style используется только для
  нижнего inset, полученного во время выполнения.

## Риски и открытые вопросы

- Навбар нужно визуально проверить на iOS и Android, включая устройства с
  нижним safe area.
- Home пока остаётся development-экраном со статусами API и WebSocket; его
  продуктовая роль потребует уточнения.
- При добавлении вложенных экранов для каждой вкладки может понадобиться
  отдельный stack navigator внутри соответствующего tab-route.
