## Контекст

Экран Swiper оставался пустой оболочкой после перехода на gluestack-ui. В этой
сессии он превратился в интерактивную ленту знакомств с жестами, а затем был
визуально приближен к карточному интерфейсу Bumble.

Параллельно выяснилось, что магазинная Expo Go на физическом iPhone не
поддерживает используемый Expo SDK: версии для новых SDK всё ещё недоступны в
App Store. Поэтому локальный workflow возвращён к development client, а запуск
backend и Metro снова объединён одной командой.

## Что сделано

### 1. Интерактивная колода профилей

- Добавлена колода из четырёх женских demo-профилей с удалёнными фотографиями,
  именем, возрастом, описанием и расстоянием.
- Реализован горизонтальный pan gesture через
  `react-native-gesture-handler`.
- Перемещение, поворот, возврат пружиной и вылет карточки выполняются через
  Reanimated на UI thread.
- Свайпы вправо и влево поддерживают порог с учётом velocity; super like
  отправляет карточку вверх.
- Те же действия доступны через круглые кнопки pass, super like и like.
- Добавлены отметки `LIKE` и `NOPE`, зависящие от положения карточки.
- Реализован возврат к предыдущему профилю через кнопку undo.

### 2. Устранение визуальных артефактов

- Убран сброс координат старой карточки до React render, из-за которого
  предыдущая фотография кратко возвращалась в центр.
- Два видимых слоя переведены на keyed-колоду: нижняя карточка сохраняет тот же
  экземпляр изображения при переходе наверх.
- `PanGesture` закреплён на постоянном контейнере колоды, поэтому обработчик не
  удаляется после первого свайпа.
- Фотографии предварительно загружаются через `Image.prefetch`.

### 3. Обновлённый мобильный дизайн

- Header получил крупный заголовок Squinder, undo и переход в меню Appearance.
- Фотография занимает основную часть экрана и имеет увеличенное скругление.
- Данные профиля размещены поверх semantic scrim в нижней части фотографии.
- Добавлены badge `New here`, краткое описание и расстояние.
- Кнопки действий перенесены поверх нижней части карточки.
- Добавлена нижняя навигация в стиле dating-приложения; рабочими остаются
  переход назад через Profile и активный раздел For You, остальные пункты пока
  обозначены как disabled placeholders.
- Все новые подписи и accessibility labels добавлены в английский i18n catalog.

### 4. Переход с Expo Go на development client

- Подтверждено, что ошибка на физическом iPhone вызвана недоступностью
  совместимой Expo Go в App Store, а не версией JavaScript-кода проекта.
- Для локальной установки выбран `expo run:ios --device`; после первой сборки
  Metro запускается в режиме dev client.
- Обнаружено, что подключённый iPhone был paired и wired, но не отображался для
  сборки из-за выключенного Developer Mode.
- Скрипты `start`, `ios` и `android` теперь используют `--dev-client` вместо
  `--go`.

### 5. Команда `make dev`

- Добавлена цель `make dev`.
- Команда поднимает PostgreSQL и API через Docker Compose, затем запускает
  Metro для установленного development client.
- `make ios` и `make android` также открывают development client, а не Expo Go.
- README обновлён: описаны первая установка на физическое устройство и
  последующие запуски через `make dev`.

## Архитектурные решения

- **Жест принадлежит контейнеру, а не карточке.** Так native gesture handler
  остаётся смонтированным при ротации профилей.
- **Следующая карточка сохраняет identity.** React key позволяет поднять уже
  загруженный слой наверх без повторного создания изображения.
- **Анимация отделена от смены данных.** Индекс профиля меняется после завершения
  вылета, а shared values сбрасываются в layout phase нового render.
- **Development client — основной native workflow.** Он не зависит от версии
  Expo Go в магазине и поддерживает установленный нативный gesture handler.
- **Scrim оформлен semantic token.** Затемнение фотографии не зависит от
  конкретной light/dark палитры.

## Риски и открытые вопросы

- Последняя визуальная итерация в стиле Bumble ещё требует smoke test на
  физическом iPhone после включения Developer Mode.
- Demo-фотографии загружаются с Unsplash и зависят от сети; для production нужны
  собственное хранилище, placeholders и политика кеширования.
- Undo пока только возвращает индекс локального demo-массива и не отменяет
  серверное действие.
- Нижние People, Liked You и Chats являются disabled placeholders без
  навигационных экранов.
- `make dev` предполагает, что development build уже установлен на устройстве;
  первая установка всё ещё выполняется отдельно через
  `pnpm exec expo run:ios --device` или Android-аналог.
